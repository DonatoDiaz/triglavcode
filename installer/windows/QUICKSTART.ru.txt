TriglavCode — быстрый старт (Windows)
======================================

1. Установка
   Запустите TriglavCode-Setup-*.exe и следуйте подсказкам.
   Права администратора не нужны: программа ставится в профиль пользователя.

2. Запуск (веб-интерфейс)
   Ярлык «TriglavCode» (в меню Пуск или на рабочем столе) запускает веб-сервер
   и автоматически открывает интерфейс в браузере. Чёрное окно консоли не
   появляется — оно скрыто.
   Из терминала достаточно набрать:
        triglavcode
   на Windows это сразу открывает веб-интерфейс. Папка установки добавлена в
   PATH; если терминал был открыт до установки — перезапустите его.

3. Остановка
   Ярлык «Остановить TriglavCode». Если браузер не открылся — ярлык
   «Лог запуска» (файл %LOCALAPPDATA%\TriglavCode\web.log): там видна причина.

4. Команды
   triglavcode web               — веб-интерфейс (по умолчанию на Windows)
   triglavcode run "..."         — разовый запуск задачи
   triglavcode serve             — headless-сервер
   triglavcode env               — переменные окружения TRIGLAV_*
   triglavcode --help            — все команды

5. Удаление
   Параметры → Приложения → TriglavCode → Удалить,
   либо «Удалить TriglavCode» в меню Пуск.
