TriglavCode — быстрый старт (Windows)
======================================

1. Установка
   Запустите TriglavCode-Setup-*.exe и следуйте подсказкам.
   Права администратора не нужны: программа ставится в профиль пользователя.

2. Запуск
   • Пуск → TriglavCode, или ярлык на рабочем столе (если выбрали при установке).
   • Либо откройте терминал (PowerShell / Windows Terminal) и наберите:
        triglavcode
   Папка установки добавлена в PATH, поэтому команда доступна из любого места.
   Если терминал был открыт до установки — перезапустите его.

3. Что дальше
   triglavcode web               — встроенный веб-интерфейс
   triglavcode run "исправь тесты" — разовый запуск задачи
   triglavcode serve             — headless-сервер
   triglavcode env               — переменные окружения TRIGLAV_*
   triglavcode --help            — все команды

4. Удаление
   Параметры → Приложения → TriglavCode → Удалить,
   либо «Удалить TriglavCode» в меню Пуск.

Документация: https://github.com/DonatoDiaz/triglavcode
