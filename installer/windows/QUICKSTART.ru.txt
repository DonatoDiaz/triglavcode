TriglavCode — быстрый старт (Windows)
======================================

1. Установка
   Запустите TriglavCode-Setup-*.exe и следуйте подсказкам.
   Права администратора не нужны: программа ставится в профиль пользователя.

2. Запуск (веб-интерфейс)
   Ярлык «TriglavCode» (в меню Пуск или на рабочем столе) запускает веб-сервер
   и автоматически открывает интерфейс в браузере. Отдельное чёрное окно
   консоли не появляется — оно скрыто.
   Чтобы остановить веб-сервер — ярлык «Остановить TriglavCode».

   Запасной вариант: из терминала
        triglavcode web
   Папка установки добавлена в PATH. Если терминал был открыт до установки —
   перезапустите его.

3. Терминальный интерфейс (TUI)
   Ярлык «TriglavCode (TUI)» открывает TUI в Windows Terminal.
   Важно: на Windows 10 нужен установленный Windows Terminal; в старом
   conhost TUI может отображаться некорректно. Тогда используйте веб-режим.

4. Что дальше
   triglavcode run "исправь тесты" — разовый запуск задачи
   triglavcode serve             — headless-сервер
   triglavcode env               — переменные окружения TRIGLAV_*
   triglavcode --help            — все команды

5. Удаление
   Параметры → Приложения → TriglavCode → Удалить,
   либо «Удалить TriglavCode» в меню Пуск.
