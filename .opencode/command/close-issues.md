---
description: Закрыть GitHub issues, связанные со вливаемой веткой/PR
---

Найди issues, которые ссылаются на текущий PR/ветку или закрываются его кодом, и закрой их с упоминанием мержа.

## Шаги

1. **Определи контекст**: текущий PR/ветка (`git branch --show-current`), связанные коммиты (`git log --oneline <base>..HEAD`).

2. **Найди связанные issues**:
   - Поиск по коммитам/PR: ключевые слова `fixes #N`, `closes #N`, `resolves #N` и их варианты (`fix #`, `close #`, `resolve #`).
   - По тексту ревью/описанию PR, если оно содержит `#N`.
   - Если токен доступа позволяет — через GitHub API (gh).

3. **Собери кандидатов**: номер, заголовок, статус. Пропусти уже закрытые и те, что не относятся к изменениям ветки (нет явной связи).

4. **Закрой** каждый кандидат: статус `closed` с reason, в комментарии укажи — какая ветка/PR влита, с ссылкой на коммит(ы). Авто-close делай ТОЛЬКО если код в ветке реально решает проблему из issue (устранённая причина, проходят тесты).

## Правила
- Не закрывай issues вслепую по простому упоминанию номера — проверь, что PR закрывает проблему.
- Не закрывай issues по ошибкам из теста без фикса в ветке.
- Если связь неоднозначна (номер в описании, но фикс частичный) — оставь issue открытым и допиши статус-комментарий с прогрессом.
