Найди подходящий скилл/команду для текущей задачи по доверенному индексу и предложи подключение.

## Шаги

1. **Запрос** — пойми текущую задачу (ключевые области: эффект, тесты, i18n/RTL, сборка, git и т.п.).

2. **Поиск в индексе** — прочитай `.opencode/tooling-index.json`. Сопоставь теги с задачей.

3. **Список кандидатов** — покажи подходящие скиллы/команды: имя, путь, trust-tier, почему подходит. Если подходящих нет — так и скажи, не выдумывай.

4. **Подключение** — для выбранного: проверь его содержимое (описание, вход, шаги) и примени только то, что релевантно задаче. Новичковый/непроверенный скилл (`review`/`quarantine` в индексе) — сначала прогони через `/vet-skill`.

## Правила
- Никогда не загружай и не запускай скиллы не из индекса без `/vet-skill`.
- Не модифицируй индекс самовольно; предложи добавлять новые записи через `/learn` или явный запрос пользователя.
- Хороший итог — это работа с одним, максимум двумя скиллами под конкретную задачу, а не «всё подряд».
